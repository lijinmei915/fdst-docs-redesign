# 基础语义

## 适用范围

Semantic/Base 将 Atomic 值映射为跨页面、跨业务成立的稳定用途。普通业务代码应先在本层查找，再考虑 Scene、Component 或 Atomic。

## 设计原则

- 语义名称描述用途，不描述当前颜色、尺寸或数值。
- 同一用途跨页面保持一致，底层值调整时不要求业务重新选择。
- 页面组合进入 Scene，组件内部结构进入 Component，业务专属规则使用私有作用域。
- 找不到匹配用途时先确认所有权，不按命名规律猜变量。

## Color

| 语义组 | 当前用途 |
| --- | --- |
| Primary、Danger、Warning、Success、Info | 实心 Default/Hover/Active/Disabled；浅背景 Default/Hover/Active |
| Text | Primary、Secondary、Tertiary、Disabled、Inverse |
| Icon | Primary、Secondary、Disabled |
| Background | Main、Container、Elevated、Disabled |
| Mask | 全局遮罩表面 |
| Border | Default、Subtle、Disabled、Focus、Error |

推荐：

```css
.warning-banner {
  color: var(--fds-g-color-warning);
  background: var(--fds-g-color-warning-background);
  border-color: var(--fds-g-border-default);
}

.warning-banner:hover {
  background: var(--fds-g-color-warning-background-hover);
}
```

不要使用：在业务组件中直接选择 Amber、Red、Green 或其他 Palette 色阶来表达状态。

## Typography

本层提供 Heading 1-5 和 Text recipe。Heading 与 Text 由颜色、字号、行高和字重组成；当前不发布字体族、Label、Caption 或 Code recipe。

推荐：

```css
.page-heading {
  color: var(--fds-g-heading-color);
  font-size: var(--fds-g-heading-2-size);
  line-height: var(--fds-g-heading-2-line-height);
  font-weight: var(--fds-g-heading-2-weight);
}
```

不要使用：只按视觉大小选择 `font-size-*`，却忽略配套行高和字重；不要在 Scene 中重定义全局字体族。

## Layout

本组包括 Disabled Opacity、Background 和 Layer。控件高度与圆角由组件契约负责。

推荐：

```css
.modal-mask {
  z-index: var(--fds-g-layer-overlay);
  background: var(--fds-g-background-mask);
}
```

不要使用：在调用方直接选择 `z-index-*` 或任意大数字；为组件尺寸猜测不存在的 Global Token。

## Effects

本组只按用途提供 None、Active、Drag、Dropdown 阴影。

推荐：

```css
.select-popup {
  box-shadow: var(--fds-g-shadow-dropdown);
}
```

不要使用：按数字猜测阴影强度；为静态卡片默认增加投影；把组件特有的 Modal 或 Drawer 投影加入 Global。

## Motion

本组提供 Feedback、Context、Disclosure、Prominent 四类 recipe。进入/退出过程分离的场景有独立 Easing。

推荐：

```css
.accordion-panel {
  transition-duration: var(--fds-g-motion-disclosure-duration);
  transition-timing-function: var(--fds-g-motion-disclosure-easing);
}
```

不要使用：业务直接选择 `motion-duration-*` 表达 fast/slow，或把 500ms 以上的特殊动画纳入 Global。

## 边界

- Base 不包含页面组合关系，通用页面、场景卡片和标题转到 [场景语义](场景语义.md)。
- 组件结构、组件状态和组件 Size API 由组件 Token 负责。
- 完整 Token 名称和当前引用关系见 [Token 目录](../reference/Token目录.md)。

## Do / Don't

| Do | Don't |
| --- | --- |
| 用 Primary、Danger、Text、Background 等用途名称表达意图 | 在业务代码中直接选择当前看起来相同的 Palette 色阶 |
| 使用完整排版和动效 recipe | 只复制其中一个值再自行补齐其他属性 |
| 将页面组合、组件结构和业务私有规则分流 | 把所有可复用样式都塞入 Global Base |
