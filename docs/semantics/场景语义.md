# 场景语义

## 适用范围

Semantic/Scene 将 Base 和 Map 组合成跨业务可复用的默认页面协议。当前仅覆盖 Page、Card、Card Title；它不定义具体工作台、详情页、仪表盘或组件内部样式。

## Page

页面协议包含画布背景、内容区 padding 和卡片间 gap。

推荐：

```css
.application-page {
  min-height: 100%;
  background: var(--fds-g-scene-background);
  padding: var(--fds-g-scene-content-padding);
}

.application-page__grid {
  display: grid;
  gap: var(--fds-g-scene-card-gap);
}
```

不要使用：在 Global Scene 中增加某个业务页面名称，或把响应式断点推断为 Scene 能力。

## Card

场景卡片协议包含 Background、Border Color、Border Width、Radius、Padding、Shadow。它描述同一页面中多张内容卡片共享的容器规则。

推荐：

```css
.scene-panel {
  padding: var(--fds-g-scene-card-padding);
  background: var(--fds-g-scene-card-background);
  border: var(--fds-g-scene-card-border-width) solid
    var(--fds-g-scene-card-border-color);
  border-radius: var(--fds-g-scene-card-radius);
  box-shadow: var(--fds-g-scene-card-shadow);
}
```

不要使用：把 `scene-card-*` 当成 Card 组件的头部、操作区、Hover、Selected 等组件 Token。

## Card Title

标题协议包含 Color、Size、Line Height、Weight 和标题区到主体内容的 Gap。

推荐：

```css
.scene-panel__title {
  margin-block-end: var(--fds-g-scene-card-title-gap);
  color: var(--fds-g-scene-card-title-color);
  font-size: var(--fds-g-scene-card-title-size);
  line-height: var(--fds-g-scene-card-title-line-height);
  font-weight: var(--fds-g-scene-card-title-weight);
}
```

不要使用：用 Scene 标题协议替代页面主标题层级，或在 Scene 中重新声明字体族。

## 业务私有场景

具体业务可直接消费默认协议，也可在自己的根作用域覆盖 Scene 变量或建立私有别名。私有变量使用业务前缀，不进入 `--fds-g-` 命名空间。

进入 FDS Scene 的候选能力必须同时满足：跨业务可复用、组合语义稳定、不依赖组件内部结构，并能只引用现有 Base 或 Map。尚未满足的能力保留为业务私有规则或待确认项。

## 边界

- Scene 不保存新的原始色值、尺寸或阴影配方。
- Scene 不能反向影响 Base 或 Atomic。
- Button、Tab、搜索框、指标、图表、进度条、状态标签及单张特殊卡片不属于当前 Scene。
