# FDS 颜色规范

## 适用范围

本页用于选择品牌色、状态色、文字色、图标色、表面色和边框色，并说明交互状态如何保持一致。状态、文本、表面和边框颜色应优先从 [基础语义](../semantics/基础语义.md) 选择。

## 设计原则

- **先选用途，再看色值。** 页面和组件优先使用 Semantic Token，不根据当前 Hex 直接选择色阶。
- **状态成组使用。** Default、Hover、Active、Disabled 使用已经配对的语义变量，不在组件内临时调亮、压暗或叠加透明度。
- **前景与表面一起评审。** 文字、图标、边框和背景必须放回真实页面层级中判断，不能只看孤立色块。
- **固定结果直接交付。** Base Palette 与 Dark Palette 保存并发布具体 Hex；浏览器运行时不计算色阶。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 主操作、品牌强调 | `--fds-g-color-primary` | 配套使用 Hover、Active 和 Disabled 状态 |
| 错误、删除和高风险操作 | `--fds-g-color-danger` | 不用红色色阶代替危险语义 |
| 风险提醒 | `--fds-g-color-warning` | 与错误状态区分，不承担阻断含义 |
| 完成、通过和健康状态 | `--fds-g-color-success` | 使用对应浅背景承载低强调反馈 |
| 信息提示 | `--fds-g-color-info` | 不替代主操作或选中状态 |
| 标题和主要正文 | `--fds-g-color-text-primary` | 次要和辅助内容使用对应文本层级 |
| 页面与容器背景 | `--fds-g-background-main`、`--fds-g-background-container` | 通过层级关系建立信息分区 |
| 普通与弱分隔 | `--fds-g-border-default`、`--fds-g-border-subtle` | 焦点和错误使用专用语义 |

## 交互状态

| 状态 | 实心操作 | 浅色反馈背景 |
| --- | --- | --- |
| Default | `--fds-g-color-primary` | `--fds-g-color-primary-background` |
| Hover | `--fds-g-color-primary-hover` | `--fds-g-color-primary-background-hover` |
| Active | `--fds-g-color-primary-active` | `--fds-g-color-primary-background-active` |
| Disabled | `--fds-g-color-primary-disabled` | 由组件禁用协议组合，不临时计算 |

Danger、Warning、Success 和 Info 使用相同的状态结构。完整名称和解析值见 [Token 目录](../reference/Token目录.md)。

## 色板预览范围

色板区域按项目9本地快照中的实际色阶生成。它只用于查看候选方案；公司 Token 的正式名称、引用和值仍以其 YAML 和 Catalog 为准。

## 使用规则

业务状态使用语义颜色：

```css
.success-note {
  color: var(--fds-g-color-success);
  background: var(--fds-g-color-success-background);
}
```

只有维护 Token 映射、实现组件私有语义或确实没有全局语义时，才直接使用正式 Palette。预览色板的项目9变量名不作为公司 Token 接入名称。

## Do / Don't

| Do | Don't |
| --- | --- |
| 用语义 Token 表达主操作、状态、文字和表面用途 | 因为当前颜色相同就直接绑定 Atomic 色阶 |
| 成组检查 Default、Hover、Active、Disabled | 在组件内用透明度或运行时颜色函数临时生成状态 |
| 在真实页面背景和层级中评审可读性 | 只看独立色块就判断颜色可用 |
| 需要新用途时先确认现有语义是否覆盖 | 在 SDS、组件或业务页面另建一套同名 Token |

## 边界

- 项目9色板快照只服务本页视觉预览，不参与公司 Token 构建或发布。
- Dark Map 预览不新增暗色 Semantic 映射或主题切换行为。
- 组件状态应建立组件语义，不让业务调用方选择原始色阶。
