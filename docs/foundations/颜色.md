# 颜色

## 适用范围

本页说明 Atomic 层颜色值域的构成、来源和消费边界。状态、文本、表面和边框颜色应优先从 [基础语义](../semantics/基础语义.md) 选择。

## 值域结构

| 类别 | 内容 | `global.source` | 用途 |
| --- | --- | --- | --- |
| Seed | 16 个有彩色系的基准输入 | `manual` | 构建期生成色阶，不供业务直接消费 |
| Palette | 每个有彩色系的固定色阶 | `generated` | 为 Semantic 和组件层提供底层色值 |
| Gray | Gray 色阶及 White、Black 别名 | `manual` | 中性色、文本和表面底座 |
| RGB | 每个有彩色系的基准色阶 RGB 通道 | `derived` | 需要 RGB 通道组合的 CSS 场景 |

当前有彩色系为 Brand、Deep Orange、Amber、Yellow、Lime、Yellow Green、Green、Teal、Cyan、Light Blue、Blue、Indigo、Purple、Magenta、Pink、Red。完整色阶和具体值见 [Token 目录](../reference/Token目录.md)。

## 使用规则

业务状态使用语义颜色：

```css
.success-note {
  color: var(--fds-g-color-success);
  background: var(--fds-g-color-success-background);
}
```

只有维护 Token 映射、实现组件私有语义或确实没有全局语义时，才直接使用 Palette。RGB Token 只提供通道值，不能单独作为 `color` 属性值。

## 来源类型

- `manual` 表示由设计或维护者直接确认的输入/枚举。
- `generated` 表示色阶在构建阶段生成后，以具体色值保存和发布；浏览器运行时不计算色阶。
- `derived` 表示从已确认颜色中派生的通道数据。

这些标记说明值的维护来源，不代表浏览器运行时行为。

## 边界

- 当前仅维护统一亮色色系，不包含暗色主题。
- 不为透明度组合重复维护所有色阶的 RGB，仅保留基准色阶 RGB。
- 组件状态应建立组件语义，不让业务调用方选择原始色阶。
- 本文不复制色阶生成算法，也不授权调整任何色值。
