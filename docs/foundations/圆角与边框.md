# 圆角与边框

## 适用范围

本页说明 Atomic/Map 的圆角和边框宽度值域，以及控件和容器应使用的 Semantic 入口。

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Radius | 0、2、4、6、8、12、16、9999px | `border-radius` |
| Border Width | 1、2px | `border-width` |

`9999px` 表示 full 圆角的固定枚举；它不是需要调用方计算的百分比。

## 使用规则

```css
.standard-control {
  border: var(--fds-g-border-width-1) solid var(--fds-g-border-default);
  border-radius: var(--fds-g-control-radius);
}

.content-container {
  border-radius: var(--fds-g-container-radius);
}
```

控件和普通容器优先使用 `control-radius`、`container-radius`。场景卡片优先使用 `--fds-s-card-border-*` 和 `--fds-s-card-radius`。

## 边界

- Border Width 只描述几何宽度，颜色和状态由 Semantic/Color 提供。
- `radius-full` 适合胶囊或圆形实现底座，不代表所有圆形组件都应直接消费 Atomic。
- 组件特殊轮廓和内部结构由组件 Token 负责。
- 本任务不调整现有圆角或边框数值。
