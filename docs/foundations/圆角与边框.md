# 圆角与边框

## 适用范围

本页说明 Atomic/Map 的圆角和边框宽度值域，以及 Scene、组件和业务容器各自负责的圆角入口。

## 设计原则

- **圆角表达对象层级。** 控件、容器和胶囊形态按职责选择，不把圆角当作独立装饰。
- **同类对象保持一致。** 同一组件或同一层级容器不因页面不同随意换档。
- **所有权优先。** 场景卡片使用 Scene，控件使用组件契约；Atomic 只作为经过评审的底层映射。
- **边框同时考虑颜色。** Border Width 只决定几何宽度，状态和强调程度由语义颜色承担。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 普通输入、按钮等控件 | Component Token / 组件 API | Global 不再发布通用控件圆角 |
| 普通业务容器 | 业务私有变量 | 没有跨业务稳定语义时不补造 Global Token |
| 通用场景卡片 | `--fds-s-card-radius` | 与卡片边框、背景和阴影成组使用 |
| 胶囊、圆形底座 | `--fds-g-radius-full` | 仅在形态确实要求时使用 |
| 默认与强调边框 | `--fds-g-border-width-1`、`--fds-g-border-width-2` | 必须同时选择合适的语义颜色 |

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Radius | 0、2、4、6、8、12、16、9999px | `border-radius` |
| Border Width | 1、2px | `border-width` |

`9999px` 表示 full 圆角的固定枚举；它不是需要调用方计算的百分比。

## 使用规则

```css
.scene-panel {
  border: var(--fds-g-border-width-1) solid var(--fds-g-border-default);
  border-radius: var(--fds-s-card-radius);
}

.pill {
  border-radius: var(--fds-g-radius-full);
}
```

控件圆角由组件 API 或 Component Token 管理，普通业务容器使用业务私有变量。场景卡片优先使用 `--fds-s-card-border-*` 和 `--fds-s-card-radius`。

## Do / Don't

| Do | Don't |
| --- | --- |
| 按控件、容器、卡片或胶囊职责选择圆角 | 为了让页面“更柔和”统一放大所有圆角 |
| 同一类组件保持统一映射 | 在业务调用处逐个覆盖组件圆角 |
| 边框宽度与语义颜色共同评审 | 只加粗边框表达所有选中、焦点和错误状态 |
| 嵌套表面由组件维护几何关系 | 页面用 `calc()` 临时计算内外圆角 |

## 边界

- Border Width 只描述几何宽度，颜色和状态由 Semantic/Color 提供。
- `radius-full` 适合胶囊或圆形实现底座，不代表所有圆形组件都应直接消费 Atomic。
- 组件特殊轮廓和内部结构由组件 Token 负责。
- 本任务不调整现有圆角或边框数值。
