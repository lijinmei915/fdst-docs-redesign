# 间距与尺寸

## 适用范围

本页区分通用间距和元素尺寸职责。Global Token 只提供 Atomic/Map 的通用间距固定枚举，不提供通用控件高度或图标尺寸。

## 设计原则

- **间距表达关系，尺寸表达对象。** Padding、Margin、Gap 使用 Spacing；控件高度和图标尺寸由组件或具体实现负责。
- **优先使用组合语义。** 页面边界、卡片间距和卡片内边距优先使用 Scene，不在每个页面重复选数值。
- **保持有限梯度。** 新场景从现有档位选择，不为轻微视觉差异新增任意 px。
- **组件尺寸由组件负责。** Button、Input 等控件高度通过组件 Size API 或 Component Token 管理，不进入 Global。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 页面内容区边界 | `--fds-s-content-padding` | 通用页面默认留白 |
| 并列或上下卡片间距 | `--fds-s-card-gap` | 保持同一场景的内容节奏 |
| 卡片内部留白 | `--fds-s-card-padding` | 不等同于 Card 组件内部全部结构 |
| 页面密度切换 | `density-{compact|comfortable|spacious}-spacing` | 与同档 Scene Line Height 成对选择；当前值见下方 JSON 表格 |
| 紧凑、默认、大号控件 | Component Token / 组件 Size API | Global 不发布通用控件高度 |
| 没有现成语义的局部布局 | `--fds-g-spacing-*` | 仅在确认属于通用间距时使用 |

## 使用规则

通用页面组合优先使用 Scene：

```css
.scene-content {
  padding: var(--fds-s-content-padding);
  gap: var(--fds-s-card-gap);
}
```

普通控件高度使用组件 Size API 或 Component Token。只有没有语义入口的局部布局，才直接选择 `spacing-*`；选定后需确认它表达的是通用间距，而不是元素固有尺寸。

页面需要统一调整信息密度时，使用对应的 Scene Density Spacing。它们可用于 `gap`、`padding` 和 `margin`，不用于控件高度；当前映射和值以上方 Catalog 表格为准。

## Do / Don't

| Do | Don't |
| --- | --- |
| 用 Scene 表达页面和卡片组合关系 | 每个页面重新选择一组近似 Padding 和 Gap |
| 将 Spacing 和元素尺寸分开判断 | 用 `spacing-*` 冒充控件高度或图标尺寸 |
| 在密集表单、列表和空状态中验证节奏 | 只看孤立方块判断间距是否合理 |
| 组件通过 Size API 管理控件尺寸 | 业务调用方猜测 Global 控件高度变量 |

## 边界

- 控件高度和图标尺寸不属于通用间距，不能用 `spacing-*` 替代。
- 当前 Global Token 不发布 Control Height 或 Icon Size；相关尺寸由组件 Size API、Component Token 或具体实现负责。
- 数字档位不代表组件 Size API，组件仍负责自己的尺寸映射。
- 当前不包含栅格、断点、容器宽度和响应式规则。
- 不新增长度 Seed，不在源值中使用 `rem` 或 `calc()`。
