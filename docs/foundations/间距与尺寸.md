# 间距与尺寸

## 适用范围

本页区分通用间距和元素尺寸。两者都属于 Atomic/Map 固定枚举，不从长度 Seed 派生。

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Spacing | 0、4、8、12、16、20、24、32、48px | `padding`、`margin`、`gap` 等通用间距 |
| Control Height | 24、28、32、36、40、48px | 输入、选择、按钮等控件外部高度底座 |
| Icon Size | 12、16、20、24、32、48px | 图标宽高底座 |

## 使用规则

通用页面组合优先使用 Scene：

```css
.scene-content {
  padding: var(--fds-s-content-padding);
  gap: var(--fds-s-card-gap);
}
```

普通控件高度优先使用 Base：

```css
.filter-control {
  min-height: var(--fds-g-control-height-compact);
}
```

只有没有语义入口的局部布局，才直接选择 `spacing-*`；选定后需确认它表达的是通用间距，而不是元素固有尺寸。

## 边界

- Control Height 和 Icon Size 不属于通用间距，不能用 `spacing-*` 替代。
- 数字档位不代表组件 Size API，组件仍负责自己的尺寸映射。
- 当前不包含栅格、断点、容器宽度和响应式规则。
- 不新增长度 Seed，不在源值中使用 `rem` 或 `calc()`。
