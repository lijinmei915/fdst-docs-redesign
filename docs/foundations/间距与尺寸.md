# 间距与尺寸

## 适用范围

本页区分通用间距和元素尺寸。两者都属于 Atomic/Map 固定枚举，不从长度 Seed 派生。

## 设计原则

- **间距表达关系，尺寸表达对象。** Padding、Margin、Gap 使用 Spacing；控件高度和图标大小使用各自尺寸体系。
- **优先使用组合语义。** 页面边界、卡片间距和卡片内边距优先使用 Scene，不在每个页面重复选数值。
- **保持有限梯度。** 新场景从现有档位选择，不为轻微视觉差异新增任意 px。
- **组件映射由组件负责。** Global 尺寸是底座，不等于 Button、Input 等组件的 Size API。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 页面内容区边界 | `--fds-s-content-padding` | 通用页面默认留白 |
| 并列或上下卡片间距 | `--fds-s-card-gap` | 保持同一场景的内容节奏 |
| 卡片内部留白 | `--fds-s-card-padding` | 不等同于 Card 组件内部全部结构 |
| 紧凑、默认、大号控件底座 | `--fds-g-control-height-compact`、`--fds-g-control-height-default`、`--fds-g-control-height-large` | 组件再映射到自身 Size API |
| 没有现成语义的局部布局 | `--fds-g-spacing-*` | 仅在确认属于通用间距时使用 |

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Spacing | 0、4、8、12、16、20、24、32、48px | `padding`、`margin`、`gap` 等通用间距 |
| Control Height | 24、28、32、36、40、48px | 输入、选择、按钮等控件外部高度底座 |
| Icon Size | 12、16、20、24、32、48px | 图标宽高底座 |

## 使用规则

通用页面组合优先使用 Scene：

```css
.scene-content {
  padding: var(--fds-s-content-padding);
  gap: var(--fds-s-card-gap);
}
```

普通控件高度优先使用 Base：

```css
.filter-control {
  min-height: var(--fds-g-control-height-compact);
}
```

只有没有语义入口的局部布局，才直接选择 `spacing-*`；选定后需确认它表达的是通用间距，而不是元素固有尺寸。

## Do / Don't

| Do | Don't |
| --- | --- |
| 用 Scene 表达页面和卡片组合关系 | 每个页面重新选择一组近似 Padding 和 Gap |
| 将 Spacing、Control Height、Icon Size 分开判断 | 用 `spacing-*` 冒充控件高度或图标尺寸 |
| 在密集表单、列表和空状态中验证节奏 | 只看孤立方块判断间距是否合理 |
| 组件通过 Size API 映射底层尺寸 | 业务调用方直接绑定 Atomic 控件高度 |

## 边界

- Control Height 和 Icon Size 不属于通用间距，不能用 `spacing-*` 替代。
- 数字档位不代表组件 Size API，组件仍负责自己的尺寸映射。
- 当前不包含栅格、断点、容器宽度和响应式规则。
- 不新增长度 Seed，不在源值中使用 `rem` 或 `calc()`。
