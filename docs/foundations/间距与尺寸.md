# 间距与尺寸

## 适用范围

本页区分通用间距和元素尺寸。两者都属于 Atomic/Map 固定枚举，不从长度 Seed 派生。

## 设计原则

- **间距表达关系，尺寸表达对象。** Padding、Margin、Gap 使用 Spacing；图标大小使用 Icon Size，控件高度由组件契约负责。
- **优先使用组合语义。** 页面边界、卡片间距和卡片内边距优先使用 Scene，不在每个页面重复选数值。
- **保持有限梯度。** 新场景从现有档位选择，不为轻微视觉差异新增任意 px。
- **组件尺寸由组件负责。** Button、Input 等控件高度通过组件 Size API 或 Component Token 管理，不进入 Global。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 页面内容区边界 | `--fds-s-content-padding` | 通用页面默认留白 |
| 并列或上下卡片间距 | `--fds-s-card-gap` | 保持同一场景的内容节奏 |
| 卡片内部留白 | `--fds-s-card-padding` | 不等同于 Card 组件内部全部结构 |
| 页面密度切换 | `density-{compact|comfortable|spacious}-spacing` | 紧凑、舒适、宽松分别为 4、8、12px，应与同档 Scene Line Height 成对选择 |
| 紧凑、默认、大号控件 | Component Token / 组件 Size API | Global 不发布通用控件高度 |
| 图标尺寸 | `--fds-g-icon-size-*` | 组件或图标实现按实际尺寸选择 |
| 没有现成语义的局部布局 | `--fds-g-spacing-*` | 仅在确认属于通用间距时使用 |

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Spacing | 0、4、8、12、16、20、24、32、48px | `padding`、`margin`、`gap` 等通用间距 |
| Icon Size | 12、16、20、24、32、48px | 图标宽高底座 |

## 使用规则

通用页面组合优先使用 Scene：

```css
.scene-content {
  padding: var(--fds-s-content-padding);
  gap: var(--fds-s-card-gap);
}
```

普通控件高度使用组件 Size API 或 Component Token。只有没有语义入口的局部布局，才直接选择 `spacing-*`；选定后需确认它表达的是通用间距，而不是元素固有尺寸。

页面需要统一调整信息密度时，使用 `density-compact-spacing`、`density-comfortable-spacing` 或 `density-spacious-spacing`。这些 Scene Token 将现有 `spacing-1..3` 映射为 4/8/12px，不创建新的尺寸值；它们可用于 `gap`、`padding` 和 `margin`，不用于控件高度。

## Do / Don't

| Do | Don't |
| --- | --- |
| 用 Scene 表达页面和卡片组合关系 | 每个页面重新选择一组近似 Padding 和 Gap |
| 将 Spacing、Icon Size 和组件尺寸分开判断 | 用 `spacing-*` 冒充控件高度或图标尺寸 |
| 在密集表单、列表和空状态中验证节奏 | 只看孤立方块判断间距是否合理 |
| 组件通过 Size API 管理控件尺寸 | 业务调用方猜测 Global 控件高度变量 |

## 边界

- Icon Size 和组件尺寸不属于通用间距，不能用 `spacing-*` 替代。
- 当前 Global Token 不发布 Control Height；控件尺寸由组件契约负责。
- 数字档位不代表组件 Size API，组件仍负责自己的尺寸映射。
- 当前不包含栅格、断点、容器宽度和响应式规则。
- 不新增长度 Seed，不在源值中使用 `rem` 或 `calc()`。
