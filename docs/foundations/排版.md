# 排版

## 适用范围

本页说明 Atomic/Map 中的字号、行高和字重值域。业务标题和正文文本优先使用 Semantic 排版 recipe；标签等组件文本由组件契约负责。

## 设计原则

- **层级来自内容结构。** 先判断标题、正文或标签职责，再选择排版组合，不按“看起来够大”临时挑字号。
- **组合完整使用。** Heading 和 Text 同时包含字号、行高和字重，避免只改一个属性破坏节奏。
- **同级保持一致。** 同一页面中承担相同职责的标题和正文使用同一 recipe，不因容器不同随意变化。
- **可读性优先。** 长文本、窄容器和中文混排需要检查换行、行高和信息密度，不能仅验收单行样张。

## 按场景选择

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 页面与内容标题 | `heading-1` 至 `heading-5` recipe | 按信息层级选择，并完整使用 Size、Line Height、Weight |
| 常规正文 | `text` recipe | 作为跨页面稳定的正文底座 |
| 标签和紧凑字段名 | Component Token | 当前不发布 Global Label recipe |
| 组件内部特殊文本 | Component Token | 不在页面调用处拼装新的全局文本角色 |

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Font Size | 12、13、14、15、16、18、20、22、24、28、32、36、40、48px | `font-size` |
| Line Height | 16、18、20、22、24、28、30、32、36、38、40、44、48px | `line-height` |
| Font Weight | 400、500、600、700 | `font-weight` |

数字档位只表达本领域的有序值，不表示 Heading 或 Text 用途。具体映射由 Semantic/Typography 保存。

## 使用规则

```css
.panel-title {
  color: var(--fds-g-heading-color);
  font-size: var(--fds-g-heading-5-size);
  line-height: var(--fds-g-heading-5-line-height);
  font-weight: var(--fds-g-heading-5-weight);
}

.panel-content {
  color: var(--fds-g-text-color);
  font-size: var(--fds-g-text-size);
  line-height: var(--fds-g-text-line-height);
  font-weight: var(--fds-g-text-weight);
}
```

Heading 与 Text 使用完整 recipe，避免只替换字号而遗失匹配的行高和字重。Label 的字号、行高和字重由组件或具体场景负责。

## Do / Don't

| Do | Don't |
| --- | --- |
| 根据内容层级选择完整 Heading 或 Text recipe | 只复制字号，遗漏配套行高和字重 |
| 在真实宽度下检查中文换行和多行节奏 | 只用英文短句或单行样张验收 |
| 组件特殊排版回到组件契约 | 在业务页面新增全局排版角色 |
| 弱化内容优先调整语义颜色和信息层级 | 单纯缩小字号制造不可读的次要信息 |

## 边界

- FDS Global Token 不发布字体族、Label、Caption 或 Code 排版 recipe；这些能力由应用、组件或具体场景负责。
- Atomic 字号和行高使用固定 px，不使用 `rem` 或运行时计算。
- 本项目不定义响应式排版阶梯。
- 组件内部排版仍可由组件 Token 约束，但应引用全局底座而非复制具体值。
