# 排版

## 适用范围

本页说明 Atomic/Map 中的字体族、字号、行高和字重值域。业务标题、正文、标签和辅助文本优先使用 Semantic 排版 recipe。

## 当前值域

| 类别 | 当前范围 | 适用属性 |
| --- | --- | --- |
| Font Family | Sans、Code | `font-family` |
| Font Size | 12、13、14、15、16、18、20、22、24、28、32、36、40、48px | `font-size` |
| Line Height | 16、18、20、22、24、28、30、32、36、38、40、44、48px | `line-height` |
| Font Weight | 400、500、600、700 | `font-weight` |

数字档位只表达本领域的有序值，不表示 Heading 或 Body 用途。具体映射由 Semantic/Typography 保存。

## 使用规则

```css
.panel-title {
  color: var(--fds-g-typography-heading-color);
  font-family: var(--fds-g-typography-heading-font-family);
  font-size: var(--fds-g-typography-heading-5-size);
  line-height: var(--fds-g-typography-heading-5-line-height);
  font-weight: var(--fds-g-typography-heading-5-weight);
}
```

使用完整 recipe，避免只替换字号而遗失匹配的行高和字重。代码或等宽文本只复用已发布的 Code 字体族，其他属性由使用场景确定。

## 边界

- 字体族是全局排版约束，不在 Scene 重定义。
- Atomic 字号和行高使用固定 px，不使用 `rem` 或运行时计算。
- 本项目不定义响应式排版阶梯。
- 组件内部排版仍可由组件 Token 约束，但应引用全局底座而非复制具体值。
