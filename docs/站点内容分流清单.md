## 生成边界

- 内部预览由 `python tools/build_docs.py --site internal` 生成到 `public/`，保留上述现有页面。它目前只是本机／局域网静态预览，**没有登录保护**。
- 对外预览由 `python tools/build_docs.py --site external` 生成到 `public-external/`。目前只收录 `external/` 下明确标记为 `audience: external`、`status: preview` 的两页说明文稿。
- 默认命令与 `--check` 同时处理两个网站。对外生成物不复制内部导航、搜索索引、Token CSS、演示数据、项目 9 色板或公司 Git 链接。
- 正式对外发布需先批准公开内容和具体 Token 版本，再建立部署及访问控制。局域网地址仅用于临时预览。
