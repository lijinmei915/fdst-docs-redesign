场景语义

适用范围

Semantic/Scene 将 Base 和 Map 组合成跨业务可复用的默认页面协议。当前覆盖页面内容间距、密度、Card、Card Title；它不定义具体工作台、详情页、仪表盘或组件内部样式。

设计原则

  • Scene 描述跨业务可复用的页面组合，不绑定具体产品或业务名称。
  • Page、Card、Card Title 按组合使用，避免页面只取其中一个值后重新拼装其余规则。
  • Scene 只引用现有 Base 或 Map，不保存新的原始色值、尺寸或阴影。
  • 业务允许在自身根作用域覆盖 Scene，但覆盖不得反向改变 Global 事实源。

Page

页面协议包含内容区 padding 和卡片间 gap。页面画布背景使用 Semantic/Base 的 --fds-g-background-main。

推荐：

.application-page {
  min-height: 100%;
  background: var(--fds-g-background-main);
  padding: var(--fds-s-content-padding);
}

.application-page__grid {
  display: grid;
  gap: var(--fds-s-card-gap);
}

不要使用：在 Global Scene 中增加某个业务页面名称，或把响应式断点推断为 Scene 能力。

Density

密度场景同时约束相对行高与基础间距，使用时应成对选择，避免排版节奏与布局留白不一致。

密度 行高倍率 对应间距 CSS 变量
Compact / 紧凑 1.2 4px --fds-s-density-compact-line-height
--fds-s-density-compact-spacing
Comfortable / 舒适 1.5 8px --fds-s-density-comfortable-line-height
--fds-s-density-comfortable-spacing
Spacious / 宽松 1.8 12px --fds-s-density-spacious-line-height
--fds-s-density-spacious-spacing

Compact 用于需要更紧凑的表格或表单；Comfortable 用于常规阅读与操作；Spacious 可用于留白更多的阅读场景。具体选用仍需在真实页面中评审。

.record-list--compact {
  line-height: var(--fds-s-density-compact-line-height);
  gap: var(--fds-s-density-compact-spacing);
}

Spacing 表示该密度的基础布局节奏，可用于 gap、padding 或 margin，不代表控件高度。密度选择不替代 Heading、Text recipe 或组件 Size API。

Card

场景卡片协议包含 Background、Border Color、Border Width、Radius、Padding、Shadow。它描述同一页面中多张内容卡片共享的容器规则。

推荐：

.scene-panel {
  padding: var(--fds-s-card-padding);
  background: var(--fds-s-card-background);
  border: var(--fds-s-card-border-width) solid
    var(--fds-s-card-border-color);
  border-radius: var(--fds-s-card-radius);
  box-shadow: var(--fds-s-card-shadow);
}

不要使用：把 --fds-s-card-* 当成 Card 组件的头部、操作区、Hover、Selected 等组件 Token。

Card Title

标题协议包含 Color、Size、Line Height、Weight 和标题区到主体内容的 Gap。

推荐：

.scene-panel__title {
  margin-block-end: var(--fds-s-card-title-gap);
  color: var(--fds-s-card-title-color);
  font-size: var(--fds-s-card-title-size);
  line-height: var(--fds-s-card-title-line-height);
  font-weight: var(--fds-s-card-title-weight);
}

不要使用：用 Scene 标题协议替代页面主标题层级，或在 Scene 中重新声明字体族。

业务私有场景

具体业务可直接消费默认协议，也可在自己的根作用域覆盖 Scene 变量或建立私有别名。私有变量使用业务前缀，不进入 --fds-g- 命名空间。

进入 FDS Scene 的候选能力必须同时满足：跨业务可复用、组合语义稳定、不依赖组件内部结构，并能只引用现有 Base 或 Map。尚未满足的能力保留为业务私有规则或待确认项。

边界

  • Scene 不保存新的原始色值、尺寸或阴影配方。
  • Scene 不能反向影响 Base 或 Atomic。
  • Button、Tab、搜索框、指标、图表、进度条、状态标签及单张特殊卡片不属于当前 Scene。

Do / Don't

Do Don't
用默认协议快速建立页面、密度和卡片节奏 为每个业务页面新增一个 Global Scene 名称
在业务根作用域中声明必要覆盖 把客户或业务私有值写回 Global Token
将 Card Scene 与 Card Component 区分 用 --fds-s-card-* 控制组件内部状态和结构
